      ⬡ agent labGeneral agentic lab · simulator
      
    
      A simulation of a general agentic lab
      
    
      A chemistry lab where an LLM plans and runs experiments. It simulates many chemical reactions and instruments,
      and the LLM controls them the same way it would control real ones — same commands, same readings.
      
    
      This online demo replays runs recorded with the simulator: browse equipment, double-click devices, and press ▶ Start to watch an experiment. Editing the bench, generating plans from papers and live LLM planning need the full app.
      

    
      What the LLM does here
      
    
      
      
      
        
      Automated experiments
      
        
      Instruments do the work: pump dosing, stirring, heating, probe / spectral readings.
      
        
        
          
      • Writes the plan from a paper or brief
        • 
          
      • Sets instrument parameters
        • 
          
      • Monitors readings and adjusts
        • 
        
      
        
      e.g. four-pump colour mixing, titration, calorimetry
      
      
      
      
      
        
      Experiments needing physical actions
      
        
      Moving containers, tubing, probes, filtering, weighing solids.
      
        
        
          
      • Human help: actions go out as task cards
        • 
          
      • Robot arm: does what it can; humans do the rest
        • 
          
      • One-off assembly is done before the run
        • 
        
      
        
      e.g. foam half-life, aspirin synthesis
      
      
      
    
      
    
      Robot-arm simulation and design are still immature: only reach (xArm 6, 700 mm), travel time,
      assumed grasp success, compatible containers and 8 basic operations are modelled; no kinematics, collisions or vision.
      Tubing, filtering and weighing solids are still done by people.
      

    
      How to use
      
    
        
      
      1. Pick an experiment in the prep library, plus executor and speed
        2. 
      
      2. Press ▶ Start (top right) to watch setup and the run
        3. 
      
      3. Press ← to generate a plan from a paper link, or fill one in by hand
        4. 
      
      4. Double-click any device for details
        5.
